concepts of OOPS -> Objects, Classes, 4 pillars mentioned below

OOPS - Object oriented programming -> so a way to create software around objects.
classes are usually used to define those objects

advantages - provide a clean and clear structure for application

**[[Encapsulation]]** - Security - Data hiding (data accessible via property only)  
**Inheritance** - Reuse of code (create method in base class and use in multiple derived class)  
**Polymorphism** - Flexibility  (same name methods can do Overloading and overriding)  
**[[Abstraction]]**

easily scalable from small to large applications  
modularity for easier troubleshooting (divide into classes and find or debug easily)


Limitations:  
Not suitable for small applications, need planning and time so not suitable for small
